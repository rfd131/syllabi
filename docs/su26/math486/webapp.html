Trouble reaching the webapp?

If your browser shows an error like ERR_TOO_MANY_ACCEPT_CH_RESTARTS or "this site can't be reached" when you click the button above:

  • Try opening the link in an incognito (private) window. This bypasses a known Chrome bug that occasionally affects *.run.app sites.
  • Or, in Chrome's settings, clear site data for *.run.app and try again from a regular window.

If neither of these works, please email the instructor with the error message you see.
